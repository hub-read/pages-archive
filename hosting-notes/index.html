GitHub 静态资源托管结论

整理自 2026-10-20 试验仓 hubgork/asset-test（已删除）；归档于本仓。

  1. raw.githubusercontent.com：仅适合 <img> 与 fetch()；CSS/JS 会被当成 text/plain 且带 nosniff，浏览器拒绝当样式/脚本。
  2. github.com/.../raw：基本只适合图片。
  3. jsDelivr（cdn.jsdelivr.net/gh/...）：CSS / JS / 图片 / fetch 可用；@main 缓存约浏览器 7 天、CDN 12 小时——生产请钉 @tag/@sha 或 purge。
  4. 以上渠道都不会渲染 HTML 页面；真正的网页必须上 GitHub Pages。
  5. 从 Pages 引用 Release 资产：<img> 与 <script> JS 可用；CSS（octet-stream）不行；iframe HTML 会下载；fetch() 无 CORS。

发布习惯：非机密预览放 Pages 子目录；大项目独立仓+Pages；很小的资源可用 Release 资产再由 Pages 引用。
